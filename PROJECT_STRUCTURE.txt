KEY FILE DESCRIPTIONS
=====================

🎨 FRONTEND COMPONENTS
----------------------

app/page.tsx (Dashboard)
├─ Fetches all patients from API
├─ Displays patient cards with risk indicators
├─ Color-coded badges (green/amber/red)
└─ Click to navigate to patient detail

app/patient/[id]/page.tsx (Patient Detail)
├─ Fetches single patient with recommendations
├─ Manages hospital switching state
├─ Three-column layout:
│   ├─ Left: ClinicalSnapshot + VitalsChart + Timeline
│   └─ Right: AntibioticPlan
└─ Real-time updates on hospital change

components/ClinicalSnapshot.tsx
├─ Displays latest vitals & labs
├─ Highlights abnormal values (red background)
├─ Shows allergy alerts
└─ Compact, scannable layout

components/VitalsChart.tsx
├─ Uses Recharts library
├─ Two charts: HR/BP trend + Temperature trend
├─ Time-series visualization
└─ Responsive container

components/Timeline.tsx
├─ Generates timeline events from patient data
├─ Surgery, lab draws, fever spikes
├─ Icon-based visual timeline
└─ Shows active risk factors

components/AntibioticPlan.tsx
├─ Primary & alternative regimen cards
├─ Show/hide detailed rationale
├─ Copy clinical note to clipboard
└─ Antibiogram summary


🔧 BACKEND API ROUTES
----------------------

pages/api/patients/index.ts
├─ Returns array of all patients
├─ Includes computed risk scores
└─ Lightweight (for dashboard)

pages/api/patients/[id].ts
├─ Accepts patientId and optional hospitalId query param
├─ Fetches patient data
├─ Computes risk score
├─ Generates antibiotic recommendation
├─ Generates explanation
└─ Returns comprehensive JSON response

pages/api/hospitals/index.ts
├─ Returns list of hospitals
└─ Used for dropdown population


🧠 CLINICAL LOGIC
-----------------

lib/clinical/riskScoring.ts
├─ calculateSepsisRisk(patient): SepsisRiskScore
│   ├─ Checks 5 criteria (SBP, RR, WBC, Lactate, Temp)
│   ├─ Assigns 1 point per criterion
│   ├─ Categorizes: 0-1=Low, 2-3=Moderate, 4-5=High
│   └─ Returns score + factor breakdown
├─ getLatestVitals(patient): object
└─ getLatestLabs(patient): object

lib/clinical/recommendations.ts
├─ generateAntibioticRecommendation(patient, hospital, riskCategory)
│   ├─ Step 1: Check penicillin allergy → Meropenem
│   ├─ Step 2: Check hospital resistance rate
│   │   └─ If pip-tazo resistance >20% → Meropenem
│   ├─ Step 3: Check creatinine >150 → Dose adjust
│   ├─ Step 4: Generate primary regimen
│   ├─ Step 5: Generate alternative regimen
│   └─ Returns structured recommendation
└─ Deterministic, rule-based (no ML)

lib/clinical/explanations.ts
├─ generateRecommendationExplanation(patient, rec, riskScore)
│   ├─ buildShortRationale(): 2-3 sentences
│   ├─ buildDetailedRationale(): full paragraph with risk factors
│   └─ buildClinicalNote(): EHR-ready structured note
└─ Template-based (could be replaced with LLM)
